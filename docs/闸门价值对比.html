核心结果：朴素臂的 12 次放行里，2 次合并会真改行为

9 案 32 群（compare v2：闸门臂按各群声明口径对账，见下方"口径尊重"节）。朴素臂（只看结构）共放行 12 次合并——其中 7 次恰好安全（填充态对换，压缩 1.004–1.143×），1 次是陷阱：TCP 孪生对（FIN-WAIT-2 ↔ CLOSING，6 格）；另有 4 次是 2048 案按声明口径的放行，闸门全部拒答——其中 1 次拒得对（键钉死旋转，740 格），3 次拒因引擎 explicit 层的群文件单映射局限（下节详述）。闸门臂放行 7 次全部零破坏，总耗时约 9.4 秒（32 群 9 案，单机实测求和，精确值见 json）。
一句话：闸门不是每次都救命——它救的正是"结构一样、事件不一样"这一类你用眼睛和结构工具都看不出的坑；其余时候它花几秒钟给你一张"压缩无害"的收据。（它也会误拒：mini2048 案当场抓到一次，见下节——误拒同样公开记录，不藏。）

怎么复跑

compare 已是法庭正式子命令（纯标准库；v2 起按群声明分派口径：explicit 群原样跑、fixed/无声明群 --strict）：
# 法庭自有九案（含 mini2048 与收编五案）
python -X utf8 -m symmetry_court compare

# 任意同格式案卷集（例：实战盲测五案的原始目录）
python -X utf8 -m symmetry_court compare --root <cases目录> --out <输出目录>
退出码 0 = 对比完成且「放行群零破坏、拒答群全部有据」一致性成立。逐案收据：verdicts/comparison.<case>.json；汇总：verdicts/comparison.summary.json。

2048 正控尝试击穿 explicit 口径的群文件单映射局限

新增 mini2048 案（2048 合并机制 2×2 确定性变体：256 态 = 81 真态 + 175 补位、4 方向键，6 群）后重跑 compare：台账现为 9 案 32 群，朴素臂放行 12（闸门拒答其中 5：TCP 孪生对 + mini2048 的 g1/g2/g3/g4），闸门放行 7（放行群破坏格 0，判据性质），一致性 PASS。总耗时约 9.4 秒（32 群单机实测求和，精确值见 verdicts/comparison.summary.json）。8 旧案收据数值零漂移（剥离计时/环境字段后逐字段核对：唯一差异 = compare v2 新增 gate_explicit_groups 字段；本页更新时独立复核确认）。
compare v2 的口径尊重：旧版闸门臂无条件 --strict，对 explicit 声明群是错误覆盖。v2 改为按群声明分派：声明 explicit（含合法 action_map）→ 不加 --strict 原样跑，损害台账按其声明映射改名事件后对账（上表带 * 行）；声明 fixed 或无声明 → 维持 --strict。声明口径下放行 = 逐格零误差，放行群破坏格 0 依旧是判据性质。
为什么 2048 的 D4 是真对称：棋盘转 90° 后按"改了名的方向键"玩，游戏一毫不差——状态置换 π 与方向键改名 ρ(π) 一一配对，π ↦ ρ(π) 满足群同态律。8 个 (π, ρ(π)) 配对由案卷生成器在 24 个动作双射中穷举推导并机器断言（唯一性 + 同态律，每次 make --check 重验）。这是 explicit 口径的第一个真实系统样本，也是"放行方向"的第一个非平凡真对称候选案卷。
工具层为什么拒它：vendored 判官的 explicit 层把一个声明的 action_map 用于闭包群每一个元素——含恒等元。恒等元在 ρ≠id 时必挂（dist(s,a) = dist(s, ρ(a)) 对所有 s,a 成立强制 ρ = 恒等），而闭包必含恒等元，所以任何非平凡"动作改名"对称在工具层结构性不可能放行。实测指纹（收据 cases/mini2048/receipts/，引擎不带 --strict）：g1 拒于恒等元（3/4 元素不过，唯一通过者恰是 rot90 本身）、g3 拒于恒等元（1/2）、g4 拒于恒等元（7/8）；恒等元对照实验双向互证——同一群文件把声明映射换成恒等后 first_bad 变为 rot90，排除"映射选错了"。同模型 g6_pads 照常放行（排除模型坏损），g2（键钉死，740 格）/g5（假群）照常拒答（判官对真该拒的照样拒）。g3 的声明口径逐格对账 = 0 破坏仍被拒，是这条局限最干净的单点证据。
翻案钩子（第 37 波）：修复归上游 wuxing-gua（逐元素 action_maps，或由生成元映射按同态律 ρ(gh)=ρ(g)∘ρ(h) 推导并验证）；修复后 g1/g3/g4 预期翻案放行——g4 全 D4 的压缩读数 4.655×（55 轨道）、g1/g2（C4）3.657×、g3 1.882×——g2/g5 维持拒答、g6 维持放行。届时上表三行"拒答（口径局限）"改"放行 ✓"、本节改一句即可。定性、诊断与 8 元素映射表：cases/mini2048/README.md（双语）；法庭判决：verdicts/mini2048.verdict.json。

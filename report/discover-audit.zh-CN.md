# discover 审计——12 案真值对账

*2026-11-07。`discover` 能力（fixed 口径候选发现）在全案卷上运行，其输出
与各案既有真值逐案对账。**结论：12/12 案对账一致，假阳性 0，预期失配
0。**下列每个数字都有本仓库收据文件或 §2 所述机器检查支撑——无一凭记忆。*

## 1. 对账双方

- **甲方——发现运行。** `python -X utf8 -m symmetry_court discover --all
  --sealed-dir <field-trial 盲测项目>/sealed`（退出码 0）。每案写出
  `verdicts/discover.<case>.json`（WL 细化、触顶或精确枚举、轨道、闸门
  臂、逐群对账、密封真值对账）与可重放候选群文件
  `verdicts/discover.<case>.candidate.json`（semantics `fixed`），由
  vendored 引擎 `check --strict` 作为闸门臂验证。
- **乙方——本审计。** 每案在进程内重跑枚举（同 cap 2000）取回*完整*
  已枚举置换集合，然后：
  1. **假阳性检查**——每个已枚举置换用审计侧独立实现的密封 fixed 判据
     `multiset(trans[π(s)][a]) == multiset{(p, π(t), r) : (p,t,r) ∈
     trans[s][a]}` 逐一验证（不用 discover 模块自己的实现）；
  2. **集合级全等**——真群被钉死的案，把已枚举集合与期望群作*集合*
     比对（四个小收编案用密封 `fixed_aut_elements`；`tcp`/`imap`/
     `hanoi3` 用显式生成的 `Sym(自由类)`；`lightsout3` 用 512 个平移
     `x ↦ x ⊕ v`）；
  3. **声明组收录**——每个群文件元素对 expected.json fixed 行
     （直接判据 + 枚举成员资格）；
  4. **收据交叉核对**——落盘判决书与复跑一致（阶、触顶标志、WL 块、
     轨道数）12/12；
  5. **基线一致性**——结果对 `verdicts/discover-baseline/` 的预注册预期
     核验（该目录先于本次运行写成；基线自身的诚实边界见其 README）。

## 3. 每案一行结论

- **`tcp`**——非离散；**发现 pads 群**（完整 5! 填充互换群，12 轨道）；
  精确阶 120；双方向冒烟契约成立（pads 被发现 / 结构孪生 `swap` 被精确
  证明不在，两方向都记录在判决书 `smoke` 块）。
- **`dhcp`**——**触顶**（≥2000；基线证书把真群阶钉在 8! = 40320）；发现
  pads 类（8 个均匀孤立填充态）；1-WL 9 块；轨道数界于 [9, 10]。
- **`imap`**——非离散；**发现 pads**（精确 24 = 4!，5 轨道）。
- **`mini2048`**——**触顶**；发现 183 态自由类（175 个填充态*外加 8 个
  真吸收死牌面*——基线预期，live 兑现）；1-WL 62 块；轨道界于
  [62, 242]；声明 explicit 口径各群在 fixed 口径下被直接判据逐一否定
  （无论触顶与否都是判定性证据）；声明的 pads 对换被直接判据证明——它
  不在前 2000 个已枚举置换内，触顶下如实记为不确定。
- **`lightsout3`**——非离散*因为真值如此*：状态图点传递，发现的群恰为
  512 阶平移群 `C2^9`（单一轨道）——与基线的机器证书集合级全等，此处由
  VF2 独立重新推导。
- **`sliding2x3`**——**触顶**；发现 pads 类（304 态）；1-WL 7 块；轨道
  界于 [7, 1018]。
- **`hanoi3`**——非离散；**发现 pads**；精确阶 120 = 5!，与
  `Sym({27..31})` 集合级全等，28 轨道——基线的条件预期（≥120、补集刚性
  时 28 轨道）被完整枚举确认。
- **`raft-etcd`**——**离散 ⇒ 恒等群**（阶 1）；密封阶相等；内容即 4 个
  单点轨道。
- **`k8s-pod-lifecycle`**——非离散；**发现 pads**（三个自由填充态上的
  S3，阶 6）；密封阶相等（密封真值自带的行启发式过预测 120 对真值 6——
  已记录在基线）。
- **`hadoop-mr-task`**——**离散 ⇒ 恒等群**（阶 1）；密封阶相等；案卷的
  |Aut| = 1 锚点。
- **`tls13-handshake`**——**触顶**（密封 15! 超出任何可达上限——诚实的
  结果）；发现 15 填充 pads 类；2000 个已枚举置换全部逐点固定 17 个协议
  态（0 违例——与密封分解结构一致）；轨道数界于 [18, 26]，1-WL 上界与
  密封分解的 18 轨道吻合。
- **`usb2-device-states`**——非离散；**发现 pads**（精确 2）；密封阶
  相等。

分布：**2 个离散恒等群**（`hadoop-mr-task`、`raft-etcd`）；**9 案发现
pads 类**（`tcp`、`dhcp`、`imap`、`mini2048`、`sliding2x3`、`hanoi3`、
`k8s-pod-lifecycle`、`tls13-handshake`、`usb2-device-states`）；**1 案
发现填充之外的非平凡 fixed 群**（`lightsout3`，平移群）；**4 案触顶**
（`dhcp`、`mini2048`、`sliding2x3`、`tls13-handshake`）；**假阳性
0**——没有任何案发现其真值不包含的对称。

## 4. 诚实注记（记录，不抹平）

- 触顶案从不报精确阶：`dhcp`、`mini2048`、`sliding2x3`、
  `tls13-handshake` 只报下界加 WL 轨道上界。凡另有精确数字在案（基线
  证书、密封真值），两侧一致。
- 触顶时声明组对已枚举集合的成员资格记为不确定；两个方向的判定性证据
  都来自直接判据（`mini2048` 判决书里逐字可见）。
- `tls13-handshake` 的密封对账在触顶下记 `order_matches: null`（推不出
  矛盾），并附结构一致性注记——不假装做了做不到的比对。
- `lightsout3` 的 1-WL 细化是横跨全部 512 态的单块——这是点传递平移群
  的真实反映，不是工具失灵；精确阶来自枚举，判决书 `timing_seconds`
  记录该案为分钟量级（其余各案与全部触顶案秒级完成）。

python -X utf8 -m symmetry_court discover --all --sealed-dir ../field-trial/sealed
python -X utf8 tools/make_discover_baseline.py --check     # 基线字节同一
python -X utf8 -m symmetry_court selftest                  # 450 契约字段，退出码 0

verdicts/discover.<case>.candidate.json --strict`（cwd `vendored/`）。
